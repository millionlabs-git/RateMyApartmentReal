## Quick Start

**RateMyApartment** is a full-stack web application for NYC apartment reviews.

```bash
# Install and run
npm install
npm run dev
```

Open `http://localhost:5000`

## Technology Stack at a Glance

```
Frontend:  React 18 + TypeScript + Tailwind + shadcn/ui
Backend:   Express + Drizzle ORM + PostgreSQL
Build:     Vite + esbuild
```

## Project Structure

```
├── client/src/          # React frontend

│   ├── pages/           # Route pages
│   └── lib/             # Utilities
├── server/              # Express API
```
